# Idea criteria (this is the file we tune)

Edit this file any time. The generator reads it fresh on every run, so changes
apply immediately. When you like or dislike ideas it posted, add notes under
"Feedback" and the next batch will adapt.

## What a good idea looks like

- **Easy to build/launch**: one person or a tiny team can get a first version
  live in days to a few weeks, using existing tools (no-code, APIs, templates).
- **Solves a real pain**: removes an annoying daily chore, saves real time or
  money, or fixes a genuinely big problem.
- **Not oversaturated**: avoid markets dominated by well-funded players or
  where thousands of identical offers already exist. Look for a niche, an
  underserved audience, or a clearly better angle.
- **Clear way to get paid**: subscription, per-job fee, or service retainer.
  Someone should be able to name who pays and roughly how much.
- **Reachable customers**: we can find the first 10 customers without a big ad
  budget (cold outreach, communities, SEO, partnerships).

## Examples of the style we like

- Cold-calling local businesses and selling them websites.
- AI auto-completer: a subscription tool that completes repetitive tasks
  autonomously.

## Avoid

- Pure get-rich-quick, MLM, dropshipping-of-generic-products, crypto schemes.
- Ideas needing heavy capital, licenses, or large teams.
- Generic "AI wrapper" ideas with no specific audience or workflow.
